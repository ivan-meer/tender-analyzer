# Тендерный Анализтор Заявок 223-ФЗ

## Описание

**Тендерный Анализтор Заявок 223-ФЗ** — это специализированное веб-приложение для юридического и операционного аудита закупок по 223-ФЗ. Оно автоматически анализирует документы закупки, выявляет риски, проверяет соответствие регламенту и генерирует отчеты в PDF.

## Основные функции

1. **Анализ проектов договоров**
   - Проверка штрафов 3% по 223-ФЗ
   - Выявление кабальных условий
   - Анализ ответственности сторон

2. **Извлечение спецификации продукции**
   - Автоматическое извлечение наименований, габаритов и параметров из ТЗ
   - Проверка требований ПП РФ 1875
   - Поиск заводских аналогов и поставщиков в РФ

3. **Генерация отчетов**
   - PDF-отчеты с юридическими выводами
   - Готовые тексты документов (запросы, требования, письма)
   - Экспорт в текстовый формат

## Технологии

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express
- **AI**: Google Gemini 3.6 Flash
- **Документы**: PDF, Word, Excel, текстовые файлы

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/your-repo/tender-analyzer.git
   cd tender-analyzer
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте файл `.env` на основе `.env.example` и укажите ваш `GEMINI_API_KEY`

4. Запустите приложение:

   ```bash
   npm run dev
   ```

5. Откройте в браузере: `http://localhost:3000`

## Использование

1. Загрузите документы закупки (Проект договора, Документацию закупки, Техническое задание)
2. Выберите тип процедуры (223-ФЗ, коммерческая закупка)
3. Нажмите "Проанализировать и Сформировать Отчет"
4. Получите детальный отчет с выявленными рисками и рекомендациями

## Особенности

- **Автоматическое извлечение спецификации** из таблиц и текстовых документов
- **Проверка на соответствие ПП РФ 1875**
- **Генерация готовых текстов документов** для тендерного отдела
- **Поддержка загрузки нескольких форматов** (PDF, Word, Excel, текстовые файлы)
