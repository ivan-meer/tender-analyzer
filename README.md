# Tender Analyzer 223‑FZ UI

> **Интеллектуальный анализ закупочной документации**

## 📖 О проекте
`Tender Analyzer` – веб‑приложение, позволяющее загружать документы тендеров (PDF, DOCX, XLSX, TXT), автоматически извлекать из них информацию и генерировать подробный риск‑отчёт в соответствии с **223‑ФЗ**. Приложение построено на **React 19**, использует **Tailwind CSS v4**, **Lucide‑react** для иконок, **Recharts** для визуализации рисков и **Framer‑Motion** для анимаций.

### Основные возможности
- **Единое окно загрузки** файлов разных форматов.
- **Темная тема** (переключаемая кнопкой, сохраняется в `localStorage`).
- **Интерактивные карты рисков** и распределение угроз по категориям.
- **Генерация PDF‑отчёта** и экспорта в TXT.
- **Поиск поставщиков** в интернете (Google‑search) с готовыми шаблонами писем.
- **Мобильная адаптивность** – упрощённый UI, скрытие скролл‑баров, компактные карточки.
- **Полный чек‑лист** подготовки и подачи заявки по 223‑ФЗ.

## 🚀 Быстрый старт
```bash
# Клонирование репозитория
git clone https://github.com/ivan-meer/tender-analyzer.git
cd tender-analyzer

# Установка зависимостей (npm, pnpm или yarn)
npm install   # или: pnpm i, yarn

# Запуск dev‑сервера
npm run dev   # http://localhost:5173

# Сборка для продакшн
npm run build

# Запуск backend‑сервера (анализ через Google‑GenAI)
node server.js
```
> **Важно:** Для работы AI‑анализа нужен файл `.env` с переменной `GOOGLE_API_KEY`. Скопируйте ` .env.example` → `.env` и укажите ключ.

## 🎨 Тёмная тема
Тёмный режим включается кнопкой **Тёмная / Светлая** в шапке. Состояние сохраняется в `localStorage` (`theme=dark|light`) и учитывает `prefers-color-scheme` пользователя. Все цвета реализованы через `dark:`‑варианты Tailwind – без CSS‑переменных.
