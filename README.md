# 🏛️ TenderAgent AI — Интеллектуальный Аудитор Госзакупок (223-ФЗ и 44-ФЗ)

**TenderAgent AI** — это профессиональная экосистема для тендерных отделов, юристов и поставщиков, предназначенная для автоматизированного юридического и операционного аудита документации торгов, выявления кабальных условий договоров, проверки национального режима (ПП РФ № 1875) и мгновенного экспорта отчетов в **Google Docs** и **Google Sheets**.

---

## 🚀 Ключевые Возможности

### 1. 🧠 ИИ-Аудит и Риск-Профилирование
- **Выявление кабальных условий контрактов**:
  - Асимметричные неустойки и завышенные штрафы (3%, 5%, 10% от цены договора).
  - Скрытые условия одностороннего отказа Заказчика.
  - Положения о закупке товаров у третьих лиц за счет поставщика.
  - Усложненный порядок сдачи-приемки и электронного актирования.
- **Национальный режим (ПП РФ № 1875 / 616 / 617)**:
  - Проверка кодов ОКПД2 и КТРУ по реестрам Минпромторга / ЕРРРП.
  - Требования к выпискам из реестра российской промышленной продукции.
- **Логистический паспорт**:
  - Сроки поставки, график заявок, условия выгрузки, подъем на этаж и пропускной режим.

### 2. 📁 Мультиформатный парсер документов и архивов
- Поддержка форматов: **PDF**, **DOCX**, **DOC**, **XLSX**, **XLS**, **CSV**, **TXT**, **ZIP**.
- Автоматическая классификация документов пакета:
  - 📄 *Проект договора*
  - 📋 *Техническое задание и Спецификация*
  - 📌 *Извещение и Документация*
  - 📊 *Сметный расчет и Прайс-лист*
- Встроенный интерактивный просмотрщик документов с подсветкой и поиском.

### 3. ☁️ Интеграция с Google Workspace
- **Google Docs**: Формирование официального экспертного заключения с паспортом закупки, реестром рисков, цитатами статей и готовыми текстами писем.
- **Google Sheets**: Создание 4-вкладочной рабочей книги:
  1. *Спецификация и ТЗ* (количества, ОКПД2/КТРУ, параметры).
  2. *Реестр Рисков Договора* (уровни риска, статьи, юридический анализ).
  3. *Паспорт и Логистика* (сроки, суммы, адреса складов).
  4. *Шаблоны Писем и Возражений* (готовые формулировки).

### 4. 🛠️ Инструменты Тендерного Специалиста
- **Проверка Заказчиков по ИНН/ОГРН**: анализ благонадежности через открытые реестры ФНС/ЕГРЮЛ.
- **Календарь процедур и дедлайнов**: контроль дат окончания подачи, запросов разъяснений и подписания.
- **Генератор писем**: шаблоны мотивированного отказа, запроса закрывающих документов, разблокировки средств на ЭТП и возражений на претензии.

## 🏗️ Архитектура и Стек Технологий

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion.
- **Backend**: Node.js, Express, Google Gen AI SDK.
- **AI-Ядро**: Интеллектуальный экстрактор риск-секций (`Priority Section Extractor`) + серверный LRU-кеш (SHA-256).
- **Экспорт**: Google Docs API v1, Google Sheets API v4, jsPDF.

## 💻 Установка и Запуск

### Предварительные требования
- Node.js 18+
- Ключ `GEMINI_API_KEY` в переменных окружения

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Сборка для продакшена
```bash
npm run build
npm start
```

## 🔒 Безопасность и Конфиденциальность
- Все обращения к AI-моделям проксируются через защищенный серверный слой.
- OAuth-токены для Google Workspace авторизуются на клиенте и используются только для создания файлов на личном Google Диске пользователя.
