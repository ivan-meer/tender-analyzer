# 🏛️ TenderAgent AI — Интеллектуальный Аудитор Госзакупок (223-ФЗ и 44-ФЗ)

**TenderAgent AI** — это профессиональная экосистема для тендерных отделов, юристов и поставщиков, предназначенная для автоматизированного юридического и операционного аудита документации торгов, выявления кабальных условий договоров, проверки национального режима (ПП РФ № 1875) и мгновенного экспорта отчетов в **Google Docs** и **Google Sheets**.

---

## 🚀 Ключевые Возможности

### 1. 🧠 ИИ-Аудит и Риск-Профилирование
- **Выявление кабальных условий контрактов**:
  - Асимметричные неустойки и завышенные штрафы (3%, 5%, 10% от цены договора).
  - Скрытые условия одностороннего отказа Заказчика.
  - Положения о закупке товаров у третьих лиц за счет поставщика.
  - Усложненный порядок сдачи-приемки и электронного актирования.
- **Национальный режим (ПП РФ № 1875 / 616 / 617)**:
  - Проверка кодов ОКПД2 и КТРУ по реестрам Минпромторга / ЕРРРП.
  - Требования к выпискам из реестра российской промышленной продукции.
- **Логистический паспорт**:
  - Сроки поставки, график заявок, условия выгрузки, подъем на этаж и пропускной режим.

### 2. 📁 Мультиформатный парсер документов и архивов
- Поддержка форматов: **PDF**, **DOCX**, **DOC**, **XLSX**, **XLS**, **CSV**, **TXT**, **ZIP**.
- Автоматическая классификация документов пакета:
  - 📄 *Проект договора*
  - 📋 *Техническое задание и Спецификация*
  - 📌 *Извещение и Документация*
  - 📊 *Сметный расчет и Прайс-лист*
- Встроенный интерактивный просмотрщик документов с подсветкой и полнотекстовым поиском.

### 3. ☁️ Интеграция с Google Workspace (Google Docs & Google Sheets)

#### 📄 Экспорт в Google Docs (`Google Документ`):
Формирует официальное экспертное заключение на вашем Google Диске, включающее:
- Паспорт закупки (заказчик, ИНН, НМЦК, дедлайны, интегральный индекс риска 0–100).
- Логистику, графики поставок и условия пропускного режима на складах.
- Реестр рисков проекта договора с точными цитатами пунктов и рекомендациями юриста.
- Спецификацию номенклатуры и анализ национального режима (ПП РФ № 1875).
- Регламент сдачи-приемки и готовые шаблоны писем поставщика.

#### 📊 Экспорт в Google Sheets (`Google Таблица`):
Создает форматированную многостраничную рабочую книгу Google Sheets из 4 специализированных вкладок:
1. **Спецификация и ТЗ**: Позиции, количества, коды ОКПД2/КТРУ, статус ПП РФ 1875, технические параметры и характеристики.
2. **Реестр Рисков Договора**: Уровни риска (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`), пункты договора, цитаты, юридический анализ и рекомендации.
3. **Паспорт и Логистика**: Сводка закупки, условия доставки, адреса складов, пропускной режим и грузополучатели.
4. **Шаблоны Писем и Возражений**: Готовые к отправке формулировки официальных запросов, мотивированных возражений и ответов на претензии.

### 4. 🛠️ Юридические и Аналитические Инструменты
- **Сравнение редакций договоров (Contract Diff)**: Автоматическое выявление расхождений между исходным проектом и встречной редакцией заказчика с генерацией протокола разногласий.
- **Генератор жалоб в ФАС РФ (ст. 105 44-ФЗ / 135-ФЗ)**: Формирование юридически мотивированного текста жалобы в Федеральную антимонопольную службу.
- **Калькулятор банковских гарантий**: Расчет суммы обеспечения заявки, контракта и гарантийных обязательств, а также ориентировочной комиссии банка.
- **Проверка Заказчиков по ИНН/ОГРН**: Анализ благонадежности заказчика и судебных рисков.
- **Импорт из ЕИС (zakupki.gov.ru)**: Быстрая загрузка данных и документов по номеру извещения.

## 🏗️ Архитектура и Стек Технологий

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion.
- **Backend**: Node.js, Express, Google Gen AI SDK.
- **AI-Ядро**: Интеллектуальный экстрактор риск-секций (`Priority Section Extractor`) + серверный LRU-кеш (SHA-256).
- **Экспорт**: Google Docs API v1, Google Sheets API v4, jsPDF.
- **Аутентификация**: Firebase Google Auth (Client-side OAuth Popup).

## 💻 Установка и Запуск

### Предварительные требования
- Node.js 18+
- Ключ `GEMINI_API_KEY` в переменных окружения

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Сборка для продакшена
```bash
npm run build
npm start
```

## 🔒 Безопасность и Конфиденциальность
- Все обращения к AI-моделям проксируются через защищенный серверный слой.
